# Code of Conduct

## Our standard

We want Nested to be welcoming, constructive, and safe for everyone. Be respectful, assume good intent, give actionable feedback, and focus disagreement on ideas and code rather than people.

Harassment, discrimination, threats, sexualized attention, deliberate intimidation, doxxing, and sustained disruption are not acceptable in project spaces.

## Enforcement

Project maintainers may edit or remove contributions and may temporarily or permanently restrict participation when behavior violates this standard. Report conduct concerns privately to the maintainers through GitHub. Maintainers will handle reports as confidentially as reasonably possible.

This policy applies in repository discussions, issues, pull requests, reviews, and other spaces where someone is representing the project.
